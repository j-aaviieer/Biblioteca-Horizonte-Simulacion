# Biblioteca Horizonte

Sitio web interactivo para la exploración de libros por categorías, visualización de recomendaciones y gestión de lecturas seleccionadas.

## Características

* Navegación con formulario de ingreso por correo y contador de libros seleccionados.
* Categorización visual: Novelas, Ciencia, Historia, Tecnología, Arte e Infantil.
* Banner promocional informativo.
* Catálogo de recomendaciones con opción para añadir títulos al carrito.

## Tecnologías Utilizadas

* HTML5
* CSS3 (`static/css/style.css`)
* JavaScript (`static/js/script.js`)

## Estructura del Proyecto

```text
.
├── index.html
└── static/
    ├── css/
    │   └── style.css
    ├── images/
    └── js/
        └── script.js

```

## Uso

1. Clonar o descargar el repositorio.
2. Abrir el archivo `index.html` en cualquier navegador web.
